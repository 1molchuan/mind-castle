念力守城 素材来源与授权
======================

本目录的素材分三类，授权各不相同。总体用途说明见仓库根目录 README.md 的「许可与用途」。

一、本项目自制（随代码一起按 MIT 许可发布，见根目录 LICENSE）
- 章节背景 bg-ch1 / bg-ch2 / bg-ch3 / bg-final、城堡 castle、法师 wizard：gpt-image-2.5 按文字描述全新生成。
- 法师动画 wizard-idle / wizard-cast / wizard-laugh：以上面的法师图为首帧，用 MiniMax H3（开源视频模型，
  MiniMax H3 Community License）生成视频后抽帧抠图；笑场动画的首帧是 gpt-image-2.5 以法师图为参考生成的笑场图。
- 小蓝鲸 whale-swim：gpt-image-2.5 生成小蓝鲸，再用 MiniMax H3 做成游动动画。
- 根目录的 icon.ico 由法师图转换而来。
- 龙息火焰、治愈光柱、Gemini 星光与魔法阵、闪电光效：游戏里用 Canvas 实时绘制（属于代码）。
- 闪电、DUANG、反弹、援军、胜负提示音：浏览器 Web Audio 实时合成（属于代码）。

二、第三方素材，带开放许可（按原许可使用，保留下方版权声明）
- 奶蛙待机、捧腹大笑 naiwa-idle / naiwa-laugh：动画帧作者 liaosongjie（github.com/liaosongjie/Codex-Voice-Input），
  GIF 由 Nailong-Studio/wallpaper（github.com/Nailong-Studio/wallpaper）整理，MIT。
- 奶蛙笑声 sfx/laugh.wav：github.com/liaosongjie/Codex-Voice-Input，MIT。
- 背手负鼠 fushu-idle：github.com/claw16/codex-pet-beishoufushu，MIT。原始照片作者不明。
- 木鱼 sfx/muyu.mp3：github.com/Ares-Chang/wooden-fish，MIT。
- sfx/punch / boing / drop / thud / squeak / boom / fanfare：Kenney（kenney.nl）音效包，CC0 公有领域；
  文件取自 github.com/series-ai/jam-ready-assets 收录的副本（impactPunch_medium_000、jump1、drop_002、
  impactSoft_heavy_000、creature4、lowFrequency_explosion_000、jingles hit_03）。

三、第三方素材，未获授权（不在本项目任何许可范围内，版权归原作者或权利人）
以下素材是网络梗图、社区二创或商业形象，仅为非商业的教学演示目的收录。不得商用；权利人如不同意收录，
请在 GitHub 仓库提 issue，我们会尽快删除。
- 肥嘟嘟袋鼠 dudu-run：github.com/inoader/codex-feidudu-pet（未声明许可）；弹窗动画与配音 dudu.webm / dudu.mp3：
  github.com/XIANG5556/fat-dudu-effect-extension（未声明许可）。原形象为美团袋鼠。
- 蓝色大肥鱼 / DeepSeek 娘 ds-think / ds-fail / ds-wave：github.com/xpy12367/codex-pet-DeepSeek-girl（未声明许可），
  社区二创形象。小大肥鱼走路 ds-walk 以该图集的侧身帧为首帧，用 MiniMax H3 生成。
- GPT 龙娘 gpt-wave：github.com/sujiu222/gpt-dragon-girl-pet（未声明许可）。
- Claude 娘 claude-wave：github.com/yuansufipa-prog/codex-pet-claude-saint（未声明许可）。
- Gemini 猫娘 gemini-wave：github.com/ethon2333-dotcom/gemini-codex-pet（未声明许可）。
- 高雅人士企鹅 peng-idle / peng-skate，以及 peng-walk / peng-dance / worker-walk / gang-walk 动画：原图为 3Dalia
  上传到 Shutterstock 的 3D 企鹅，取自 github.com/Moeary/Penguin-Meme-Maker 收录的模板，rembg 抠图；
  动画以这些图为首帧，用 MiniMax H3 生成。
- 奶龙 nl-front，以及 nl-walk / nl-sleep / nl-happy / nl-cry 动画：第七印象出品的动画形象，原图取自
  github.com/CristinXie/NaiwaOrNailong-dataset，rembg 抠图；动画以这些图为首帧，用 MiniMax H3 生成
  （哭泣的首帧是 gpt-image-2.5 以原图为参考生成的全身图）。
- 「迪普西克公司老板梁武谷」直播画面 liang：网上流传的 DeepSeek 创始人肌肉男 AI 恶搞图
  （转载见 x.com/wsjack/status/2083865874671509506），原作者不明。仅作娱乐性二创，无任何贬损意图。
